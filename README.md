# Портфолио проектов по системному анализу (School 21)

В репозитории собраны практические работы, выполненные в ходе обучения по направлению **"Бизнес и Системный анализ"** в Школе 21 (Сбер). Проекты идут последовательно и охватывают полный цикл работы аналитика: от декомпозиции задачи и анализа стейкхолдеров — до проектирования данных, диаграмм процессов и управления требованиями.

## 🛠 Ключевые навыки и проработанные области

### 1. Работа с требованиями (Requirements Engineering)
- Выявление и классификация: типы, уровни и зависимости требований; модели "As Is" и "To Be"
- Техники сбора требований и их документирование
- Функциональные и нефункциональные требования, управление требованиями на протяжении проекта
- Артефакты: User Stories (с критериями приёмки и тест-сценариями) и Use Cases

### 2. Моделирование бизнес-процессов и систем
- Нотации: BPMN (диаграммы дорожек), DFD (потоки данных), диаграммы состояний
- Таблицы решений для формализации сложных бизнес-правил
- Контекстные диаграммы и определение границ системы

### 3. Проектирование данных и доменное моделирование
- Выявление сущностей домена, построение информационной модели, проверка через CRUD-матрицы
- ER-диаграммы, атрибуты, словарь данных
- UML-диаграммы классов и объектов

### 4. Управление процессом, стейкхолдерами и интеграцией
- Анализ заинтересованных сторон: их проблемы, потребности, влияние на проект
- Декомпозиция задач, глоссарий проекта, роли в команде, этапы SDLC
- Проектирование пользовательских интерфейсов и системная интеграция

## 📂 Структура репозитория

| Папка | Тема | Что внутри |
|---|---|---|
| `BSA00_Decomposition` | Декомпозиция задач | Разбивка проекта на подзадачи, глоссарий терминов |
| `BSA01_Stakeholders` | Стейкхолдеры | Анализ заинтересованных сторон, матрица влияния |
| `BSA02_Requirements` | Требования | Бизнес- и пользовательские требования, модели As Is / To Be |
| `BSA03_HowToRequirements` | Техники выявления требований | Методы сбора требований и их документирование |
| `BSA04_Domains` | Доменное моделирование | Сущности домена, информационная модель, CRUD-матрица |
| `BSA05_Diagrams` | Диаграммы | Контекстные диаграммы, диаграммы состояний |
| `BSA06_BPMN` | BPMN | Диаграммы бизнес-процессов с дорожками |
| `BSA07_UserStory` | User Stories | Пользовательские истории с критериями приёмки |
| `BSA08_UseCase` | Use Cases | Сценарии взаимодействия пользователя с системой |
| `BSA09_Objects_and_Classes` | UML | Диаграммы классов и объектов |
| `BSA10_FunctionalRequirements` | Функциональные требования | Спецификация функциональных требований |
| `BSA11_UserInterfaces` | Интерфейсы | Проектирование и описание пользовательских интерфейсов |
| `BSA12_NonfunctionalRequirements` | Нефункциональные требования | Требования к производительности, безопасности и др. |
| `BSA13_RequirementsManagements` | Управление требованиями | Отслеживание изменений, приоритизация, трассировка |
| `BSA14_SystemIntegration` | Интеграция систем | Взаимодействие системы с внешним окружением |

> 📌 Названия и содержание нескольких папок (BSA03, BSA09, BSA11, BSA14) на скриншоте были обрезаны — проверь точные названия в самом репозитории перед публикацией.
